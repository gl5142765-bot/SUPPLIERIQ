Why This Is Classification

The target Risk\_Level represents classes, not a continuous number.

The model must predict whether a supplier belongs to one risk category or another.

This makes the problem a classification task, not regression.



Baseline Model

A baseline classification model was trained as the first benchmark.

The baseline helps us understand how well the current feature set performs.

It gives a reference point for future model improvements.



Why the Baseline Matters



It shows whether the selected features are useful.

It gives a simple starting performance score.

It helps compare future models against a basic standard.



Short Note



Supplier risk prediction is a classification problem because the target is categorical.

The baseline model is the first simple model used to set a performance reference.

Future models will be compared against this baseline.
